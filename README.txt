Hiraoka_iT — Portfolio Website
================================

Как запустить:
1. Распакуйте архив.
2. Откройте файл index.html двойным кликом в любом браузере (Chrome, Edge, Firefox, Safari).
3. Ничего устанавливать не нужно — сайт полностью автономный.

Структура:
  index.html          — главный файл сайта (вся вёрстка, стили и скрипты внутри)
  assets/avatar.jpg   — ваш аватар
  README.txt          — этот файл

Что внутри:
- Тёмная премиальная тема с анимированным градиентным фоном
- Стеклянная навигация с плавным скроллом и подсветкой активного раздела
- Полоса прогресса прокрутки сверху
- Анимации появления блоков при прокрутке (staggered reveal)
- Анимированные полоски навыков и счётчики процентов
- Бегущая строка со стеком технологий
- Аватар с вращающимся светящимся кольцом
- Кнопки копирования почты и Discord-ника
- Полностью адаптивно: десктоп, планшет, телефон (бургер-меню)
- Поддержка prefers-reduced-motion
